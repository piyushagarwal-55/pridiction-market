            block.number,        ← From blockchain
            player_address,      ← Unique to player
            bet_count           ← Increases each bet
        )
        
        Casino CANNOT control these inputs!

     2. Atomic Transaction Execution
        ─────────────────────────────────
        User submits bet → Single transaction:
          1. Take USDT           ✓
          2. Generate random     ✓
          3. Calculate result    ✓
          4. Compare result      ✓
          5. Pay if won         ✓
          6. Emit event         ✓
        
        Casino CANNOT intervene mid-transaction!

     3. Immutable Smart Contract
        ─────────────────────────────────
        Code is PERMANENT on blockchain
        Casino CANNOT modify it
        Anyone can VERIFY the code

     4. Transparent Results
        ─────────────────────────────────
        Every bet recorded on-chain
        Anyone can VERIFY calculations
        Anyone can CONFIRM payouts

     5. Automatic Payouts
        ─────────────────────────────────
        Smart contract ENFORCES payouts
        Casino CANNOT block or delay
        Transfer happens IN SAME TRANSACTION

  📊 EXAMPLE: Roulette Bet
     ──────────────────────────
     Player bets 100 USDT on number 7
     
     1. Contract takes 100 USDT ✓
     2. Contract generates random:
        random = hash(blockchain_data)
        result = random % 37 = 15
     3. Contract compares: 15 ≠ 7
